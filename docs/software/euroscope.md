## Подготовка

Мы рекомендуем использовать **EuroScope версии 3.2.3.2** ([скачать](https://euroscope.hu/install/EuroScopeSetup.3.2.3.2.msi)).

Чтобы приложение работало корректно и без ошибок, необходимо скачать:

* **[Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170#latest-microsoft-visual-c-redistributable-version)**: Обеспечение корректной работы EuroScope 

* **[TrackAudio](https://www.vatsim.uk/api/trackaudio-latest)**: Голосовая связь с пилотами
* **[Сектор-файл](https://files.aero-nav.com/)**: Плагины и конфигурации для диспетчеров


## Сектор-файл
Первым шагом необходимо создать папку для распаковки и дальнейшего хранения сектор-файла.
Для этого создаем папку с названием “UNNT” в любом удобном для вас месте.

Мы рекомендуем создать папку по адресу: ```“..\Рабочий стол\UNNT”```

После создания папки распаковать архив в нее.
Если у вас уже была установлена предыдущая версия сектор-файла, то ее необходимо **полностью удалить**.

!!! danger "Внимание!"
    **<u>Запрещено</u>** хранение использованного вами сектор-файла в сервисах облачного хранения, **<u>передача</u>** и другое перемещение папки с сектор-файлом из вашего ПК.

## Первый запуск EuroScope

После запуска EuroScope появится диалог выбора профиля

В этом окне перейдите в папку, куда вы распаковали сектор-файл, и откройте файл с расширением ```.prf```


!!! tip "Совет по настройке"
    При первом запуске **обязательно** проверьте меню `OTHER SET`. Там **<u>не должно быть</u>** галочек напротив:
    
    - `Auto load last profile on startup`
    - `Auto save profile on exit`
    
    Если они стоят — снимите их, иначе клиент будет загружать старые настройки
